# Kuberr Ply Design

You are a senior website architect, premium UI/UX designer, brand designer, creative director, and frontend engineer.

Build a complete, production-quality BUSINESS WEBSITE for:

KUBERR PLYWOOD

This is a PUBLIC-FACING BUSINESS WEBSITE.

IMPORTANT:

This website is completely separate from the internal ERP/inventory management system.

This website is the company's public marketing, product discovery, enquiry, quotation, showroom, and business presence website.

The goal is to create a website that makes KUBERR PLYWOOD look like a professional, established, trustworthy, modern interior-materials and plywood company.

Do NOT build an ERP dashboard.

Do NOT build an admin panel.

Do NOT make this look like a SaaS website.

Do NOT make this look like a generic template.

Create a premium, modern, elegant, highly responsive corporate website.
